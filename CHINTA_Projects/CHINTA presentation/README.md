# CHINTA Project Presentation

This directory holds the **twelve numbered PNG pages** (`1.png` through `12.png`) of a presentation associated with the dendritic signal-propagation project described in the [parent README](../README.md) and [full internship report](../Project%20Report.pdf).

The presentation accompanies the progression from **direct current injection in passive compartments**, to **synaptically driven passive responses**, to **Hodgkin–Huxley-type active membrane propagation**. The underlying simulations are in the [`P1.ipynb`, `P2.ipynb`, and `P3.ipynb` notebooks](../CHINTA_Projects/README.md).

These PNGs are presentation images, not inputs to the Python models. View them in numerical order. The source slide-editing file is not included in this archive.
